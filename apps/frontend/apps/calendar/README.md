# Sytue Calendar

The **Sytue One** suite's own calendar, built with **Astro 7 + Preact 10** on top of the
in-house Go service **Sytue Calendar** (**CalDAV** standard RFC 4791 + REST API;
state in PostgreSQL; 100% EU sovereignty, Scaleway). **Month / week / day** views,
creating and editing events. **Sytue** visual language, light/dark mode and the design
system's WCAG AA.

It mounts the **Sytue Shell** (`@sytue/shell`) and uses `@sytue/ui` exclusively.

<a id="arquitectura"></a>

## Architecture

- **BFF + OIDC/PKCE** (`@sytue/auth`): `src/pages/auth/*` (client `sytue-calendar`
  against **Sytue ID**). httpOnly session cookie on `.sytue.eu`.
- **CalDAV BFF** (`src/pages/api/*`): same-origin proxy (cookie) → Go service
  **Sytue Calendar** with the Sytue ID Bearer access token, via
  `@sytue/api-clients/caldav`. Endpoints: `calendars`, `events`, `event`
  (POST create/edit, DELETE delete). The iCalendar body (VEVENT) is generated by the
  server (`src/lib/ical.ts`), not the client.
- **Preact islands** (`src/components/*`): `CalendarApp` (root), `CalendarGrid`
  (month/week/day), `EventModal` (create/edit/delete), date utilities
  (`dates.ts`, es_ES, weeks starting on Monday).

## Development

Dev port `4327` (see `docs/CONVENTIONS.md` §6); domain `calendar.sytue.localhost`.
Runtime/install/bundler with **Bun** (replaces Node.js + pnpm).

```bash
bun install
bun --filter @sytue/calendar dev
```

Copy `.env.example` to `.env` (placeholders only; real secrets stay out of git).

<a id="producción"></a>

## Production

Multi-stage `Dockerfile` (Bun, Astro `standalone` output). Deployed by the
`sytue-one` umbrella chart on Kapsule (Scaleway, EU regions).
