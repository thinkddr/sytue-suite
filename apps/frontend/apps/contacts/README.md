# Sytue Contacts

The **Sytue One** suite's own contacts app, built with **Astro 7 + Preact 10** on top of
the in-house Go service **Sytue Contacts** (**CardDAV** standard RFC 6352 + REST API;
state in PostgreSQL; 100% EU sovereignty, Scaleway). Filterable list and contact
card, create / edit / delete. **Sytue** visual language, light/dark mode and
WCAG AA from the design system.

It mounts the **Sytue Shell** (`@sytue/shell`) and uses `@sytue/ui` exclusively.

<a id="arquitectura"></a>
## Architecture

- **BFF + OIDC/PKCE** (`@sytue/auth`): `src/pages/auth/*` (client `sytue-contacts`
  against **Sytue ID**). httpOnly session cookie on `.sytue.eu`.
- **CardDAV BFF** (`src/pages/api/*`): same-origin proxy (cookie) → Go service
  **Sytue Contacts** with the Sytue ID Bearer access token, via
  `@sytue/api-clients/carddav`. Endpoints: `addressbooks`, `contacts`, `contact`
  (POST create/edit, DELETE delete). The vCard 4.0 body is generated by the server
  (`src/lib/vcard.ts`), not by the client.
- **Preact islands** (`src/components/*`): `ContactsApp` (root), `ContactDetail`
  (contact card, with the cross-app action _Send email_ → Sytue Mail), `ContactModal`
  (create/edit/delete).

<a id="desarrollo"></a>
## Development

Dev port `4328` (see `docs/CONVENTIONS.md` §6); domain `contacts.sytue.localhost`.
Runtime/installation/bundler with **Bun** (replaces Node.js + pnpm).

```bash
bun install
bun --filter @sytue/contacts dev
```

Copy `.env.example` to `.env` (placeholders only; real secrets stay out of git).

<a id="producción"></a>
## Production

Multi-stage `Dockerfile` (Bun, Astro `standalone` output). Deployed by the
`sytue-one` umbrella chart on Kapsule (Scaleway, EU regions).
