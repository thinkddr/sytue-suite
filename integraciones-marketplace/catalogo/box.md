# Box — SAML SSO (plan Business+)
1. Box Admin Console → **Enterprise Settings → User Settings → Single Sign-On**.
2. «Configure SSO»: sube el **certificado de Sytue ID** y pega **Login URL**; **Name ID** `Primary email`.
3. Activa por grupos (o global) y prueba.
En Sytue Platform no hay campos: Box solo necesita los datos del IdP.
**Verificar**: login sin contraseña de un usuario del grupo SSO.
