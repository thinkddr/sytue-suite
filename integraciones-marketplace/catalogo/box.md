# Box — SAML SSO (Business+ plan)
1. Box Admin Console → **Enterprise Settings → User Settings → Single Sign-On**.
2. “Configure SSO”: upload the **Sytue ID certificate** and paste the **Login URL**; **Name ID** `Primary email`.
3. Enable it per group (or globally) and test.
There are no fields in Sytue Platform: Box only needs the IdP data.
**Verify**: passwordless login by a user in the SSO group.
