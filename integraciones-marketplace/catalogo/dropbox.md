# Dropbox — SAML SSO (plan Team+)
1. dropbox.com/admin → **Settings → Single sign-on**.
2. «Add sign-on» → sube el certificado y pega el **Sign-in URL** de Sytue ID; Name ID `email`.
3. Aplica a todos o por grupo; «Optional» hasta verificar.
Sin campos en Sytue Platform: Dropbox consume solo los metadatos del IdP.
**Verificar**: login desde la suite de un usuario del dominio.
