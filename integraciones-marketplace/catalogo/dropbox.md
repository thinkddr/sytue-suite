# Dropbox — SAML SSO (Team+ plan)
1. dropbox.com/admin → **Settings → Single sign-on**.
2. “Add sign-on” → upload the certificate and paste the Sytue ID **Sign-in URL**; Name ID `email`.
3. Apply to everyone or per group; “Optional” until verified.
No fields in Sytue Platform: Dropbox only consumes the IdP metadata.
**Verify**: sign-in from the suite with a user from the domain.
