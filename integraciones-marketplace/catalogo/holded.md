# Holded — API key
1. Holded → avatar → **Configuración → API** → genera una clave.
2. Sytue Platform → Integraciones → **Holded**: pega la clave → «Conectar».
**Nota**: la clave vale para TODA la cuenta — usa una clave por integración y revísala si alguien sale de la empresa.
**Verificar**: listado de contactos/facturas en el panel del gateway.
