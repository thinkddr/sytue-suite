# Holded — API key
1. Holded → avatar → **Configuración → API** (Settings → API) → generate a key.
2. Sytue Platform → Integrations → **Holded**: paste the key → “Connect”.
**Note**: the key is valid for the ENTIRE account — use one key per integration and review it if someone leaves the company.
**Verify**: contacts/invoices are listed in the gateway panel.
