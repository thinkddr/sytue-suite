# HubSpot — SAML SSO (Enterprise plan)
1. HubSpot → **Settings → General → Log in → Single sign-on**.
2. Upload the certificate and paste the Sytue ID URLs; **Name ID** `email`; identifier format “Email”.
3. Copy the **SP Entity ID** (`https://app.hubspot.com/login/sso/…`) and the **ACS URL** to the Sytue Platform detail card.
4. Enable “Require SSO” only for the intended users.
**Verify**: HubSpot's “Verify SSO” and sign-in from the launcher.
