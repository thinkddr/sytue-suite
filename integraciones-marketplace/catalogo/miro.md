# Miro — SAML SSO (Enterprise plan)
1. Miro **Company Settings → SSO / SAML** → “Add SAML”.
2. Sytue ID metadata + Name ID `email`; copy Miro's **SP Entity ID/ACS** to the integration page.
3. Relax “Domain approval” only after verifying.
Nothing special: it is the standard in-house SAML flow.
