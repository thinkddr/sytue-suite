# monday.com — SAML SSO (Pro+ plan)
1. monday.com Admin → **Security → SAML** → “Modify”.
2. Upload the Sytue ID certificate; paste the Sign-in/Logout URL; **Name ID** `email`.
3. Save under “Optional SSO” until tested; copy monday's **ACS/Entity** to the detail card if your template asks for it.
**Verify**: an admin logs in from a private window before switching to “Mandatory”.
