# monday.com — SAML SSO (plan Pro+)
1. monday.com Admin → **Security → SAML** → «Modify».
2. Sube el certificado de Sytue ID; pega Sign-in/Logout URL; **Name ID** `email`.
3. Guarda en «Optional SSO» hasta probar; copia el **ACS/Entity** de monday a la ficha si tu plantilla lo pide.
**Verificar**: login de un admin desde ventana privada antes de «Mandatory».
