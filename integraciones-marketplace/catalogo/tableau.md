# Tableau Cloud — SAML SSO
1. Tableau Cloud → **Settings → Authentication → SAML** → «Import metadata» con los de Sytue ID.
2. Atributos: `username` = correo; **Name ID** `emailAddress`.
3. Anota en la ficha tu **pod** (`https://10az.online.tableau.com`, `https://eu-1a.online.tableau.com`…) y el **site** (slug de la URL).
4. Guarda y prueba en una ventana privada antes de «Required».
