# Tableau Cloud — SAML SSO
1. Tableau Cloud → **Settings → Authentication → SAML** → “Import metadata” with the Sytue ID ones.
2. Attributes: `username` = email; **Name ID** `emailAddress`.
3. Note down in the card your **pod** (`https://10az.online.tableau.com`, `https://eu-1a.online.tableau.com`…) and the **site** (the URL slug).
4. Save and test in a private window before “Required”.
